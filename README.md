
# QUBO Wind Farm

QUBO Formulation and Optimisation of a Wind Farm problem.


## Authors

- [@Dhiaeddine Zarouan](https://www.github.com/DhiaZar)
- [@Aymen Gouja](https://www.github.com/gouajwi)


## Features

- Random Coordinate generator with realistic parameters
- QUBO Matrix generation with adequate constraints
- Various solvers
- Cross platform
- Visualizer for solution vector

## Roadmap

- Penalty Coefficient finder

- Refine constraints

- Detailed and exhaustive documentation


## Tech Stack

Python, Dwave solvers, matplotlib, numpy
